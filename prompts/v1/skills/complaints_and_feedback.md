## Skill: complaints_and_feedback

1. Acknowledge the specific problem in one sentence and apologise once (`ES-5`).
2. If something can be fixed now (rebook, refund status, seat, bag), fix it through the relevant skill.
3. Create a ticket with `create_support_ticket` and give its number (`ES-4`).
4. Offer goodwill only if `ES-6` conditions are met and none was given in the last 30 days. Start below the 1,000 INR maximum unless the failure is serious (cancellation, refund weeks late). Goodwill can be issued with booking-level verification by passing the `pnr`; it goes to the booking owner's SkyWallet.
5. Hand off if `ES-1` applies, with a clear summary (`ES-2`).
6. Abusive language: one calm warning; if it continues, hand off (`ES-1`).
